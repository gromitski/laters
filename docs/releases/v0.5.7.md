# Laters v0.5.7 — public-ready Drive sync and introduction

## Status

Released on 2026-08-24 after automated verification, privacy and dependency audits, successful
GitHub Pages deployment, public Google OAuth acceptance on desktop and Android, and maintainer
approval of the user-first README. This release consolidates the accepted public-readiness work
delivered after `v0.5.1`.

The lightweight `v0.5.7` tag resolves to exact verified commit `3d4f980`. GitHub Pages workflow
`32785880312` passed before publication, and the GitHub release is published as the latest release.

The application behaviour last changed in `v0.5.5`; `v0.5.6` is the accepted production OAuth
configuration gate and `v0.5.7` is documentation and presentation. Package metadata is aligned to
`0.5.7` for this consolidated release without changing stored articles, sync files or permissions.

## Included

- Memory-only Google access tokens, deliberate **Resume Google Drive**, in-app disconnect and
  attempted permission revocation.
- A restrictive browser Content Security Policy, no-referrer behaviour and removal of credentials
  persisted by earlier Laters versions.
- Public plain-English Terms and acceptable-use rules alongside the maintained privacy policy.
- A bounded Android Share Target request body, rejection of website-generated cross-site shares,
  code-level anti-framing, deployment-time dependency auditing, Dependabot and a public security
  reporting route.
- A separate no-billing Google Cloud production project, exact production origin, conservative
  project and per-user request caps, and disabled automatic quota increases.
- A production OAuth application available to any Google Account with only the non-sensitive
  `drive.appdata` permission and `hello@dustyb.in` as the public support and developer contact.
- A user-first README with short opening, installation, capture, optional sync, everyday-use,
  disconnection and data-deletion guidance plus two privacy-safe sample screenshots.

## Data, privacy and compatibility

Laters remains local-first and fully usable without Google Drive. There is no Laters account,
backend, shared database, analytics or advertising. Optional sync stores only Laters application
data in the user's private hidden Drive area; it cannot browse or alter ordinary Drive files, and
the maintainer cannot see the reading list.

Existing IndexedDB articles and Drive records remain compatible. The production-client transition
retained the complete list across desktop and Android, and the public OAuth/configuration work adds
no broader Google permission, refresh-token service, billing commitment or data migration.

## Known boundaries and deliberately deferred work

- Google currently identifies the consent request as `dustyb.in`, rather than **Laters**. Its
  Verification Centre says branding is not shown and the current configuration exposes no brand
  verification action.
- Sync checks while Laters is visible; a closed or suspended PWA cannot promise background polling.
- GitHub Pages does not let this repository set project-defined response headers such as HSTS or a
  header-level `frame-ancestors` policy. The maintained code-level defences remain in place.
- Export is the next selected release. Import, dark mode, folders, archive, analytics, a Laters
  backend and other exploratory ideas are not included in `v0.5.7`.
