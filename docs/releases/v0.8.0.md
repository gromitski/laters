# Laters v0.8.0 — dark mode

## Status

Approved for release on 2026-08-26 after automated verification, privacy and dependency audits,
successful GitHub Pages deployment and published maintainer acceptance.

Package metadata is aligned to `0.8.0`. The accepted public candidate is commit `ee685b4`; GitHub
Pages workflow `32962723247` passed after the final menu-order correction. No application data,
Google permission or network boundary changes in this release.

## Included

- An accessible **Appearance** radio group with **System**, **Light** and **Dark** choices.
- Experimental Google Drive sync retained as the first menu section, Import and Export second, and
  Appearance at the bottom immediately above the footer.
- System as the default, following operating-system colour preference and reacting to changes while
  selected.
- A browser-local Light or Dark override that applies immediately and persists across reloads.
- A token-based dark palette across the reading list, menu, article action sheet, title dialog,
  status presentation, Privacy and Terms.
- Pre-display theme resolution and runtime browser theme-colour updates to avoid showing the wrong
  application theme during startup.
- Package-derived **Version 0.8.0** presentation in the existing menu footer.

## Data, privacy and compatibility

The only new stored value is `laters-theme-preference`, containing `system`, `light` or `dark` in
local browser storage. It is not included in IndexedDB articles, CSV Import or Export, Google Drive,
pending operations or credentials. Theme selection makes no network request and does not mutate the
reading list or sync queue.

Existing articles, bookmarks, saved times, deliberate titles, CSV files, private Drive records and
service-worker update behaviour remain compatible. The runtime browser colour follows the effective
theme; the static web-app manifest retains a white launch background because one manifest cannot
represent each browser's local selection.

- The installed-app launch splash remains the static light manifest colour.
- Appearance is device- and browser-local rather than synced, imported or exported.
- This release adds no reading-time data shown in exploratory imagery, article-content fetching,
  automatic title enrichment, images, custom palettes, schedules, folders, archive or analytics.
- No later product slice is accepted. Open possibilities are maintained separately in
