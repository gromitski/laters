# Laters v0.6.0 — portable reading-list export

## Status

Released on 2026-08-25 after automated verification, privacy and dependency audits, successful
GitHub Pages deployment and published maintainer acceptance on macOS Chrome.

The lightweight `v0.6.0` tag resolves to exact verified release commit `60794b0`. GitHub Pages
workflow `32847501931` passed before publication, and the GitHub release is published as the latest
release.

Package metadata is aligned to `0.6.0`. This release adds an explicit local export without changing
stored articles, Google Drive data, sync permissions or the existing reading-list interactions.

## Included

- **Download CSV** in the main application menu, available with or without Google Drive.
- A documented, version-1 UTF-8 CSV contract with `url`, `title`, `created` and `tags` columns.
- Newest-first rows and sortable UTC filenames such as
  `laters-export-v1-2026-08-25T09-08-07Z.csv`.
- Namespaced `laters-bookmarked` and `laters-title-edited` tags that preserve stable user state.
- Reversible protection for titles beginning with spreadsheet formula characters, marked with
  `laters-protected-title`.
- A conventional browser download on every supported platform. Whole-list export does not use the
  operating-system share chooser because its destinations do not reliably include a save location.

## Data, privacy and compatibility

Export is entirely user initiated. Laters reads the resolved local list and starts a local browser
download; it does not upload the file, send it to Google Drive or perform a sync request.

The CSV contains no Google credential, token, account or connection information; local article or
operation identifiers; pending sync operations; deleted-article history; Drive file or checkpoint
metadata; or other private implementation bookkeeping. Export does not mutate the reading list or
pending sync queue.

The format is designed to remain useful as a spreadsheet and for third-party tools that accept CSV
link imports. A future Laters Import may consume it, but this release does not promise third-party
interpretation of dates or tags.

Existing IndexedDB articles, Drive records and operation files remain compatible. There is no data
migration, backend, Laters account, analytics, automatic export or new Google permission.

## Known boundaries and deliberately deferred work

- Import is not included. File validation, duplicate handling, merge behaviour and Google Drive
  reconciliation must be agreed as a separate `v0.7.0` product slice.
- The browser chooses its configured download location and may download without presenting a save
  dialogue.
- Article-level **Share** remains a separate URL-only interaction and continues to use the system
  share sheet.
- Dark mode follows Import on the accepted roadmap. Folders, archive, analytics and a Laters backend
  remain outside the roadmap.
