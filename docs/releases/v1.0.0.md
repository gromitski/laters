# Laters v1.0.0 — complete personal reading queue

## Status

Released on 2026-08-26 after automated verification, privacy and dependency audits, successful
GitHub Pages deployment and published maintainer acceptance of the Bookmark filter.

Package metadata is aligned to `1.0.0`. The lightweight `v1.0.0` tag resolves exactly to release
commit `565cd59`; GitHub Pages workflow `32967914059` passed for that commit. `v1.0.0` is the latest
public GitHub release. No application data, Google permission or network boundary changes in this
release.

The accepted application candidate was commit `3690512`. GitHub Pages workflows `32967338184` and
`32967338912` both passed for that commit. The maintainer accepted the installed Android and macOS
browser result and authorised release closure before the package-only release preparation.

## Included

- One restrained **Show bookmarks** text action beside the existing list count, changing to
  **Show all** in the filtered view.
- The complete **Saved articles** queue retained as the default on every load.
- A transient **Bookmarked articles** view that preserves existing newest-first order.
- View-specific semantic headings, accessible list labels, counts and a clear filtered empty state.
- Predictable focus recovery and status messaging when an article is unbookmarked and leaves the
  filtered view.
- Existing Paste and CSV Import reveal behaviour retained by returning to the complete list when
  needed.
- Existing Delete/Undo Ghost presentation retained for bookmarked articles while filtered.
- Package-derived **Version 1.0.0** presentation in the existing menu footer.

## Data, privacy and compatibility

The filter is presentation state held only for the current page. It is not retained across reloads,
installations or devices and adds no article field, IndexedDB store, database migration,
local-storage preference, Drive file, sync operation, CSV column or recovery tag.

Existing articles, bookmarks, saved times, deliberate titles, CSV files, private Drive records,
pending operations, credentials and service-worker update behaviour remain compatible. Export
continues to include the complete stored list and Import continues to compare against it regardless
of the currently visible view.

The release performs no new network request, contacts no publisher and adds no article-content,
image or metadata fetching, Laters backend, account, analytics, public list, automatic upload or
paid service.

## Product completion and future boundary

This release completes the personal-reading-queue MVP: capture, opening, deletion and Undo,
bookmarks and filtering, publisher recognition, mobile gestures, URL-only sharing, Paste, title
editing, responsive desktop access, optional private Google Drive sync, CSV Import and Export, and
System, Light and Dark appearance.

Laters now moves to a complete, maintenance-focused state rather than assuming another feature
roadmap. Grouping and tagging may be explored later, but they are not currently necessary, approved
or versioned. Search, sorting, archive, automatic tidy rules, reading-time estimates, remote title
enrichment, images, folders, a Laters backend and analytics remain outside `v1.0.0`.
