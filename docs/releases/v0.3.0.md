# Laters v0.3.0 — quicker mobile actions

## Status

Released on 2026-08-22 after automated verification, GitHub Pages deployment and focused physical
Android acceptance. This is a backward-compatible minor release built on `v0.2.0`; it changes the
interaction shell without changing saved-item data.

## Included

- A selectively registered, exactly pinned Ionic Core 9 interaction shell without an application-
  framework migration.
- Right swipe reveals a neon-lime Bookmark or Remove action. Tapping it or completing the swipe uses
  the same persistent bookmark operation as the visible Star.
- Left swipe reveals a warning-red Delete action. Tapping it or completing the swipe uses the same
  seven-second Undo path as the visible Delete control.
- Touch or pen long press opens a focused action sheet with Read now, Bookmark or Remove bookmark,
  Delete and Cancel. Right-click, Shift+F10 and the Context Menu key provide equivalent non-touch
  routes.
- Gesture arbitration prevents a swipe or long press from also opening the article. Normal vertical
  scrolling and quick row opening remain intact.
- Coarse-pointer article text no longer triggers Android selection and dictionary UI during the
  application long-press gesture; fine-pointer desktop selection remains available.
- Delete, expiry and Undo replace only the affected row, preserving the viewport when an item is
  removed lower in a long queue.
- Designed link focus replaces the unrelated native black outline. The accepted Undo control has a
  white centre, neon-lime outside countdown ring and black Undo glyph.

## Accessibility and safety

The semantic title link, visible Star and visible Delete button remain available with their existing
accessible names and target sizes. No operation requires a gesture. The action sheet provides focus
containment, Escape and backdrop dismissal, destructive semantics for Delete and focus restoration.
Swipe movement suppresses the synthetic row click that could otherwise open an article, and each
gesture routes through the existing bookmark or deletion operation rather than maintaining parallel
state.

## Privacy and data compatibility

This release adds no storage field, migration, backend, account, analytics, API key or remote
service. Existing `v0.1.0` and `v0.2.0` IndexedDB records remain valid. Ionic code is bundled into the
application and no component library is loaded from a CDN. The existing direct publisher-favicon
privacy boundary is unchanged.

## Verification and acceptance

- All 68 automated tests passed across 13 files.
- TypeScript checking, the Vite production build and service-worker generation passed.
- The public-build audit passed without a secret, local-path, source-map or unintended static
  third-party resource finding.
- GitHub Pages deployment passed and the public origin served the matching production assets.
- Browser checks covered the mobile layout, action-sheet keyboard route and focus behaviour,
  bookmark state synchronisation, both configured swipe sides and their semantic colours.
- Physical Android testing confirmed the gesture shell, then exposed and rechecked the native link
  outline, dictionary selection and lower-page Delete/Undo scroll-jump corrections. The maintainer
  accepted the final bidirectional swipe treatment and Undo presentation for release.

## Deliberately deferred

Reading time, alternative ordering, title enrichment, dark mode, export, sync, folders, archive,
article images and additional capture paths remain exploratory. Release `v0.3.0` adds no Share or
Copy-link action to the long-press sheet because neither has an accepted application behaviour or
visible gesture-free alternative.
