# Laters v0.2.0 — easier scanning and selective retention

## Status

Released on 2026-08-22 after automated verification, GitHub Pages deployment and focused physical
Android acceptance. This is a backward-compatible minor release built on the accepted `v0.1.0`
personal MVP.

## Included

- Persistent per-article Bookmark buttons with accessible pressed states, supplied hollow and
  bright-lime filled star artwork, and a subtle bookmarked-row wash.
- Backward-compatible optional bookmark data. Existing IndexedDB records remain valid; re-sharing
  an exact URL, Delete and Undo preserve the bookmark state without changing queue order.
- Fixed 22px publisher source markers. Laters first renders a deterministic local rounded-square
  fallback, then fades in a successfully decoded `/favicon.ico` from the saved article's exact
  origin.
- Stable fallback characters and colours derived from the canonical normalised hostname using the
  documented FNV-1a UTF-8 hash and six-colour accessible palette.
- Refined first-title-line source-marker alignment for one-line and multi-line article titles.
- Whole-row pointer opening on non-interactive row space, using the existing semantic title link's
  destination and new-tab behaviour.
- Safety exclusions for links, buttons, form controls, non-primary or prevented clicks, selected
  text and Ghost/Undo rows. The row adds no redundant keyboard tab stop or gesture system.

## Privacy and data compatibility

Saved URLs, titles, timestamps and bookmark state remain local in the browser. This release adds no
account, backend, analytics, sync, API key or central favicon service. Favicon attempts go directly
to the saved publisher's origin with a no-referrer policy, so that publisher may receive the device
IP address, request timing and ordinary request context. Failures remain silent local fallbacks.

The IndexedDB database and object-store version remain unchanged. Bookmark state is an optional
field, allowing records created by `v0.1.0` to remain valid without migration or rewriting.

## Verification and acceptance

- 66 automated tests passed at release closure.
- TypeScript checking and the Vite production build passed.
- The public-build audit passed without weakening its third-party-resource or privacy checks.
- GitHub Pages deployment passed and preserved the existing same-origin reading list.
- Physical Android testing accepted bookmark persistence and visuals, favicon success and fallback,
  offline fallback, multi-line alignment, row-space opening, title-link behaviour, Bookmark/Delete
  separation, scrolling, text selection and Ghost/Undo behaviour.

## Deliberately deferred

Long press, an action sheet and swipe-to-delete remain unselected. Before implementing them, the
project requires a bounded architecture investigation comparing maintained focused libraries or
frameworks against scroll arbitration, accidental activation, accessible dialog behaviour,
gesture-free alternatives, bundle weight and incremental adoption cost. Reading-time extraction,
sorting, title enrichment, dark mode, export, sync, folders and archive also remain exploratory.
