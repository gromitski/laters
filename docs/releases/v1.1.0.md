# Laters v1.1.0 — CSV-supplied reading times

## Status

Implemented as a verified local candidate on 2026-08-28. Publication through GitHub Pages and
maintainer acceptance of the installed result remain. No `v1.1.0` tag or GitHub release exists.

## Included

- An optional, case-insensitive `readtime` CSV column containing a positive whole-number estimate
  in minutes.
- Blank and absent reading-time values that retain the established Import behaviour.
- Complete pre-review validation with the existing row-numbered, all-or-nothing failure contract.
- Optional article storage that needs no IndexedDB database migration.
- Preservation through existing pending operations, private Google Drive snapshots and merges.
- Version-2 CSV Export with `readtime` after `tags` and a blank value where the estimate is unknown.
- A quiet **≈ N min** label after the existing saved-time metadata only when an estimate exists.
- Package-derived **Version 1.1.0** presentation in the application menu.

## Compatibility and privacy

Android Share, Paste, existing stored articles, original version-1 exports, URL-only CSVs and files
using only the earlier optional columns remain valid without reading-time data. Exact canonical URLs
retain the add-only Import rule and are never enriched or overwritten by a later CSV row.

Laters does not fetch article content or metadata, contact a publisher, calculate or edit an
estimate, sort by reading time or total the queue. The release adds no backend, account, analytics,
automatic upload or paid service. Import and Export files retain their existing local privacy
boundary.
